# markdown_to_pdf

A fast, fully-featured Markdown to PDF converter with live preview.

## Features
*   **Live Preview**: Real-time markdown rendering using Vite + React.
*   **Advanced Formatting**: Supports KaTeX natively and Mermaid diagrams.
*   **Custom CSS Panel**: Fine-tune your document styles easily.
*   **PDF Generation**: High-quality exports via `WeasyPrint`.
*   **AWS S3 Integration**: Automatically uploads PDFs to S3 and returns a presigned secure download URL.
